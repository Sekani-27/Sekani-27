## 🔹 Faultline — Production Failure Evidence System

[View Repository](https://github.com/Sekani-27/Faultline-)

A **deterministic causal-evidence system** for investigating production failures, built as a full-stack product with an interactive investigation interface and evidence-processing backend.

Instead of allowing an AI model to simply decide what caused an incident, Faultline evaluates competing explanations against observable engineering evidence.

### Key capabilities

* Interactive incident investigation UI
* Production incident analysis
* Canonical engineering evidence model
* Deterministic causal claim evaluation
* Supporting and contradicting evidence
* Rule traces
* Human review workflow
* GitHub engineering evidence ingestion
* **Evidence Debt** for identifying missing observability

### Stack

`TypeScript` · `React` · `Next.js` · `Cloudflare Workers` · `D1` · `Drizzle ORM` · `GitHub API`

> Faultline turns post-incident analysis from a narrative into an inspectable and challengeable evidence process.
